# 世界观公理与统一判据

> 本文档是 CyanoOrg 哲学体系的结构层正典（第零层）。价值观入口见 [values.md](values.md)——种子语境的展开；本文给精确机制表述（智能/负熵/差分等术语以此为准）。

---

## 1. 公理

| # | 公理 | 一句话 |
|---|---|---|
| A1 | **过程公理** | 价值在过程，产物只是收据 |
| A2 | **经验公理** | 智能以语料为根基、在交互中生长——沉淀使之可能，交互使之活化。押注：人类数据天花板已可触，增量全在经验（实证中命题，非定论） |
| A3 | **主权公理**（结构性表述） | **主权 = 负熵积累的归属权**——运行史活在谁的基底上，收益就积累给谁；不是规范性愿望，是其他三条公理生效的所有权条件 |
| A4 | **真实公理**（差分表述） | **真实 = 不可廉价伪造的差分改变**——时间性证据会遭伪造攻击（假节奏/空转刷痕迹），「因过程而变的行为差分」反事实可查、难持续造假。本公理界定**出处可验**（authenticity）：担保「确出自其所声称的过程」，不担保内容为真——内容真假由验真质询（C3）与裁决层接力 |

**合拢一句：过程即价值，经验即智能，主权即尊严，真实即时间**——在合成时代，人保有真实的方式，是拥有自己的过程、经验与代理。

思想源：桑德森（创作者经济）、曾鸣（智能商业）、Sutton/LeCun（经验时代）、熵垒视角的综合。

## 2. 统一判据（A1 的机制化）

**过程性 = 被过程改变的能力 = 状态中积累了路径依赖、不可廉价复制的秩序（负熵）。**

三个必要条件，独立可测：**积累**（状态改变且留存）、**路径依赖**（快照搬运无效）、**不可廉价复制**（拷走产物 ≠ 拷走能力）。

四尺度现形——同一判据，同一句危机诊断「**产物引擎没有过程**」：

| 尺度 | 判据实例 | 危机诊断 |
|---|---|---|
| 个体 | 被创作过程改变的创作者 | AI 跳过「成为创作者」的旅途 |
| 组织 | 被自身运行改变的组织（战略涌现） | 无生成能力的科层 |
| 机器 | 被交互经验更新的内部状态 | 无世界模型、无经验的语言统计 |
| 市场 | 给路径依赖积累定价 | 合成产物淹没信号 |

操作含义：让 agent 从绝热会话变成耗散结构——dispatch→verify→trace→归因→记忆→进化的全套机制，就是这套判据在机器尺度的工程化。

## 3. 动力学：熵垒与耗散结构

- **文化/规范体系 = 耗散结构 + 势垒动力学**。它不生产信任，它延缓信任的耗散；停止做功不是「内容变旧」，是垒在降解。
- **有效时隐形**：垒的工作方式是让坏事不发生——文化健康的组织系统性低估自己的文化。看组织文化别看价值观海报，看什么行为「理所当然」、什么行为「代价高」。
- **最小维持流量**：耗散结构对维护是阈值响应不是剂量线性——**半维护 ≈ 不维护**。规范三态：在垒（流量≥阈值）/ 死垒（挂着但低于阈值，负资产）/ 已放塌（明确废除并留档）。
- **垒 = 两径成本差**（Δ = 越轨成本 − 合规成本）：加高越轨成本与降低合规成本（工具化/内化/模板）等价——**把规范做进工具也是付垒的账单**。
- **不可移植的是垒，可移植的是生成器**：抄得走纸面制度，抄不走让它自我强制的运行史；但可以开源「让运行史被生产出来的实践」。
- **抽象规范是容器，具体案例是垒**：规范必须锚定事故与证据——案例不是附录，是主要形态。

熵减经济学三则（成本侧展开）：

- **熵减成本转移**：把人类技能压入系统，压进去的从来不是技能本身，是技能的**过去时**——已结构化、可显式化的部分（工作流契约、门禁、验证规则全是这种压缩形态）；技能的**现在进行时**（判断、品味、目标感）压不进去。且转移不是零和搬运而是形态转换——压缩完成的瞬间产生两笔新账：**结构税**（引擎演进须同步契约）与**维持账单**（留存、清理、治理审计）——压入的秩序不自动保值，它以治理能量计息。
- **自动熵减天花板**：**可验证性到哪，自动熵减就能到哪。** 封闭域（评价函数完美可显式化，如自博弈棋类）可彻底自动；开放域（评价函数自身在漂移）天花板为**维持性自动熵减**——系统可自动维持既有秩序、发现局部反熵结构，但**不能原创减熵方向**。天花板是移动边界不是固定墙：形式化能力每前进一步，可验证域就扩一块。**「彻底自动」的语义边界**：只要目的函数仍外生，就不是彻底自动；系统自生成目的 = 换物种问题，不是天花板问题——目的若可能生成，也只能从长程交互中涌现，不能从架构图中设计。
- **方向性熵减留在人**：系统能维持秩序、能收敛，但「往哪减、为什么减」的排序仍来自人——不是能力不足，是方向性选择在机制上外生于系统。残留关系类似董事会对 CEO：方向审计而非方向生成。

## 4. 趋势判断

1. **真实感三段史**：被背书的真实（机构代理）→ 被稀释的真实（合成消灭「便宜的信任」）→ 被经营的真实（真实从名词变动词，个人重塑真实的唯一路径是拥有不可外包的过程）——真实感的去中心化。
2. **分发换轴**：内容稀缺时代平台权力来自控制分发；生成成本趋零后，**稀缺的不再是内容，是可信的过滤**。个人 agent = 代表个人的对抗性过滤器。
3. **定价基准迁移**：产物外观 → 过程证据 → **差分改变**。过程证明会遭伪造攻击（假节奏、空转刷痕迹）；伪造时长便宜、伪造学习贵——终点是「因过程而变的可验证」。真正的不变量是**事故→学习转化率**。
4. **产业三阶段**：基础设施 → 海量应用 → 原生应用；模型公司宿命是基础设施。下一空缺生态位是 agent 的「浏览器」——大概率不是流量入口而是**信任入口**（agent 间互验协议层）。
5. **架构侧合流**：知识长在载体上（mortal computation）、以经验而非语料为源（Era of Experience）、以预测而非重建为形。LLM 是无过程的产物引擎；**trace = 经验时代的燃料**——把工作过程变成可验证的轨迹，是在提前铸造那个时代的战略储备。

## 5. 公共性：广场是协议

**新公共性 = 验证的共享，不是内容的共享。** 没人能共享全部信息流，也不该只共享算法挑的；可以共享的是验证过程——agent 之间对同一事实的独立验证记录互验。**共同现实 = 可互验验证层的交集，不是内容的交集。**

协议设计原则见 [广场协议](../../protocols/zh-CN/p1-agora.md)（P-x）。

## 6. 哲学 → 产品的推导（方向性）

公理往系统架构的推导：**引擎层让过程可执行、编排层让过程可组织、觉知层让过程可验证、皮肤层让过程可感知、记忆体系让过程属于个人**。

- **自证先行**：吃自己的狗粮是过程公理的开源表述；不可伪造层（事故档案/修复轨迹/运行数据）是它的门面形态——市场对「真实」的判定正从「看起来有」迁移到「验证过在运行」。
- **叙事 vs 能力**：叙事是容器（话术数周复刻），证明是垒（时间×事故×修复）。复利组合只有一个形态：能力先行，叙事作为其渲染层。
- **生成器开源**：开源「让运行史被生产出来的实践」（门禁设计、评审流程、失败分类学），生成物（运行史）作为不可伪造资产留在实践者手里。

## 7. 哲学自身的过程性

公理当**工作假设**，不等完美再推导产品；让产品决策反向测试哲学，每次冲突暴露假设边界。配套检验（世界观作为熵垒——**从不拦截决策的世界观是海报**）：重大决策记一行「第零层判定」（公理对该决策说什么、有没有说不）；若连续数季全是「同意」，哲学已容器化。
