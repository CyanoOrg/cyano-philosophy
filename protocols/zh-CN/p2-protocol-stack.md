# P-2 协议栈：迭代分层

## 定义

协议栈是广场协议落地的**迭代架构**——不是一次性建成的系统，是四级台阶：每层解决一类争议，成熟度自下而上递增（验证最成熟，分配最理论）。**理论-执行剪刀差就画在这四级台阶里。**

与 [P-1 广场协议](p1-agora.md) 的关系：P-1 定义协议的性质与治理形态（是什么），本文定义协议的生长路径（怎么长出来）。

## 迭代分层（成熟度自上而下递减）

### ① 验证层——无争议事实（成熟度：已在实践中存在）

- **机制**：回放即终结，机器判定；吸收大部分「事实争议」。
- 验证内建是协议必要性质之一（〔p1·必要性质〕④）——这一层不是附加组件，是协议的地基。

### ② 互认层——标准前置（成熟度：相邻动作，允许开始）

- **机制**：把「标准争议」前置成契约——A 域的验证收据可被 B 域验证；**只动证据互认，不动决策权**。
- 这是最近的可行动作点：不预设广场本体，先让收据跨域可验。

### ③ 裁决层——争议收敛（成熟度：原型已在内部实践）

**争议三类型**（裁决层只处理第三种）：事实争议 → 大部分被验证层吸收；标准争议 → 大部分被互认层前置；**责任争议（反事实/意图/外部性）→ 裁决层的核**。

**分级法院**（每层成本低一个量级；上层 = 下层的上诉法院；按争议标的自动建议终结层——阻尼设计）：

| 层级 | 形态 | 成本 |
|---|---|---|
| L0 自动裁决 | 协议内建规则 | 零人工 |
| L1 对账裁决 | 双方+轨迹三方对账 | 多数争议止于此 |
| L2 仲裁网络 | 信誉抽签、agent 优先，人保留终审否决 | 低 |
| L3 法律系统 | 现实法院（人身/刑事/超管辖额） | 现实成本 |

**最小核三件套**（多了是过度设计）：①**轨迹可回放**——取证成本≈0，裁决经济学的基础；②**stake 预置**——质押化/保险化，违约自动执行；③**先例引用语法**——判例法式，先例可 fork、随版本代谢。

**设计原则**：目标 = 最小入庭率（越闲越好）；裁决内建于轨迹（gevulot 双职：平时定价，争议时证据）；先例是活的；退出权 = 终极制衡。

**红线**：链上只执行，不裁决——裁决结果作为数据进链执行，链本身无管辖权（防赌场化的结构性保护）。

### ④ 分配层——价值回流（成熟度：理论，远期条款）

- 分配单位 = 可验证轨迹（非产物快照）；可见性 = 定价函数；回流契约 + 公共池（维护性熵减定价）——细则见 P-1。
- 已知前置缺口：回路转速与认知资本的计量未定义；公共池暂不工程化。

## 五步靠近路径（顺序视角；与四层同构——层次与顺序互为印证）

1. **收据设计考虑外部验证者**（验证层的自证延伸）
2. **跨域引用**——A 域收据被 B 域验证（互认层的第一个具体动作）
3. **裁决域扩展**——争议裁决的契约化与试点
4. **轻量多人试验田**——广场雏形的最小多人形态
5. **不可伪造层**——运行史作为外部可验证的资产（地基与门面是同一件事）

**纸面纪律**：广场协议本体的解锁条件 = 不可伪造层出现第一个外部验证者——在那之前，收据跨域引用与验证层建设不受限（它们是地基，不是广场）。

## 与种子的关系

差分枝的阶梯化落地：验证→互认→裁决→分配，每一层都是「不可廉价伪造」在协作深度上的进阶——验证层让事实难伪造，裁决层让责任难逃逸，分配层让贡献难挪用。主权枝的保障在退出权与「链上不裁决」红线。
