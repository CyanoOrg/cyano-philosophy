# 世界观四公理与第零层：合成时代的核心哲学

> **演化档案 · 第一部 · 第 3 篇（部终）**。09-13 晚对谈、09-14 落库与裁定。原文脱敏收录，编者按见文末。

---

**问题**：剧变时代的真正议题——世界观/价值观 → 推导产品方向：人在剧变时代如何重塑真实；信息结构如何换轴；我们的核心哲学是什么。

## 一、真实感的三段历史

- **被背书的真实**（旧时代）：真实性由机构代理——媒体、学历、品牌、平台认证。你信，因为它替你信过。
- **被稀释的真实**（现在）：所有背书者同时失效——内容可合成、文凭在贬值、亲眼所见可疑。合成不是消灭真实，是消灭「便宜的信任」。
- **被经营的真实**（正在开始）：真实感从名词变动词——不是属性，是持续实践。个人重塑真实的唯一路径：**拥有不可外包的过程**——亲手做、长期做、公开做。

熵垒语言：旧时代机构替你维护信用之垒，新时代每个人得自己维护自己的运行史。**这是真实感的去中心化**。

## 二、分发权力的换轴

中心化平台的权力来自内容稀缺时代的「控制分发」。当生成成本趋零、内容无限，**稀缺的不再是内容，是可信的过滤**。个人定制化的本质：个人 agent 作为「代表你的过滤器」与平台算法对抗——从「你是被分发的对象」变成「你有对抗性代理」。

过程性基础设施的天然位置：**个人 agent 的过程性基础设施**（记忆、上下文、运行史都属于个人）。

## 三、四公理

| # | 公理 | 一句话 | 来源线 |
|---|---|---|---|
| 1 | **过程公理** | 价值在过程，产物只是收据 | 桑德森 / 熵垒 / 曾鸣三线交汇 |
| 2 | **经验公理** | 智能在交互中生长，不在语料中沉淀 | Sutton / LeCun——人类数据天花板已摸到，增量全在经验 |
| 3 | **主权公理**（初版表述） | 注意力、数据、记忆、agent 应属于个人 | 个人 agent 是主权的延伸，不是平台的留存钩子 |
| 4 | **真实公理**（初版表述） | 真实是时间性证据，不可合成 | 能证明的只有运行史 |

**合拢一句：过程即价值，经验即智能，主权即尊严，真实即时间**——在合成时代，人保有真实的方式，是拥有自己的过程、经验与代理。

往五层图景的推导：引擎层让过程**可执行**、编排层让过程**可组织**、觉知层让过程**可验证**、皮肤层让过程**可感知**、记忆体系让过程**属于个人**。

> **第零层（Layer Zero）**：哲学层不是五层之外的第六层，是五层的「为什么」。四公理是五层的公理基础。

（注：表中 3、4 两条为初版表述——次日的裁定将其升级，见 §七。正典定稿见 worldview。）

## 四、张力：定制化的尽头是不是一亿个茧房

个人真实感最大化（我的 agent 只看我想看的）与共同现实的公共性（社会需要共享的事实底座）直接冲突。产品前途在此分岔：**茧房优化器** vs **共同现实的协议**。

当晚的回答：个人定制化应该还是要有公共广场。两个意象：

- **gevulot**（《量子窃贼》忘川城隐私协议）：公与私不是两个空间，是**每个人可编程的频段**——默认共享的社会里，个体用协议精细划界，边界本身公开可协商。公私边界不是墙，是协议。
- **《中国2185》全民投票汇总**：公共意志可实时汇聚呈现——流动的共识信号。原著同时埋了警告：汇总全民意志 ≠ 得到智慧，无阻尼的实时公投是灾难。

**讨论中的推进**：

1. **新公共性 = 验证的共享，不是内容的共享**。没人能共享全部信息流，也不该只共享算法挑的。可以共享的是**验证过程**——我的 agent 与你的 agent 对同一事实的独立验证记录互验。共同现实 = 可互验验证层的交集，不是内容的交集。
2. **公共广场是协议，不是地方**（The commons is a protocol, not a place）。这消解「定制化 vs 茧房」的假两难：个人频道负责「为我过滤」，协议层负责「彼此校验」——茧房发生在无互验的定制，不在定制本身。
3. **agent 间互验协议是真正的空缺生态位**。曾鸣说 Agent「浏览器」没看到雏形——也许因为都在找「人找 agent 的入口」，而真正的生态位是「agent 与 agent 互信的协议层」。谁的轨迹能被别人验证，谁就在建广场的地基。
4. **带阻尼的分层共识已有微缩原型**：2185 的教训是实时全量公投无阻尼=灾难；门禁、授权证据、逐级上报本质上是有结构的授权流——一个微缩公共协议的日常实践。

## 五、哲学本身也应该是过程性的

四公理 + 广场协议先当**工作假设**，不等完美再推导产品；让产品决策反向测试哲学，每次冲突暴露假设边界。哲学用过程法生长，而非先写完再执行——这是过程公理对哲学自己的应用。

## 六、收尾问句（当晚留下）

> 四条公理 + 广场协议这个组合，有哪条你觉得还「不够硬」——是有隐约的怀疑，还是都站得住只是还没长全？

## 七、§六 的裁定（次日评审）

按硬度排序的判断与处置：

- **过程公理最硬**：有机制（统一判据：路径依赖的负熵积累）、有四尺度证据。
- **经验公理次之**：Bitter Lesson 有七十年经验证据，但「人类数据天花板」仍是实证中命题——作为押注方向足够硬，作为定论要留余量。
- **主权公理按初版表述最弱** → **裁定：采纳结构性表述**。熵垒视角加固：主权 = **负熵积累的归属权**——若运行史/记忆/轨迹活在别人的基底上，过程、经验、真实三个公理的收益都积累给平台而非个人。主权不是道德主张，是**其他三条公理生效的所有权条件**——从「应然」变「结构必然」。
- **真实公理需要第三站 sharpening** → **裁定：采纳差分表述**。「真实 = 时间性证据」已被推进为「真实 = 不可廉价伪造的**差分改变**」——纯时间证据可刷，差分改变难造假。公理内核不变，表述升级。
- **广场协议的硬度在采用动力学**：协议生态位有鸡蛋问题，但有自身实践的带阻尼共识起点，不依赖先有生态。（维持，未触发处置）
