# 认知共创网络下篇：网络拓扑、组织原型与广场协议

> **演化档案 · 第三部 · 第 8 篇**。09-19。原文脱敏收录，编者按见文末。

---

**问题**：从「个人 agent 组织工作台」走向多人认知共创网络，拓扑、组织与协议分别要回答什么——①多主体化后架构上什么是可流动的、什么必须分层；②Valve 式人才密度自组织对网络形态的启发与教训；③广场协议应具备什么特点、以什么顺序靠近。

## 一、总论

三场对谈一条线：**拓扑（两层架构）→ 组织（节点质量门槛）→ 协议（广场六特点）**。合拢句：**认知共创网络 = 认知界的 git**——其节点门槛由过程证据而非招聘官判断，其公共层由协议而非平台承载。

## 二、从单节点到网络节点：轨迹/理解两层架构

「动态流动的认知不断逼近真实」与不可伪造层不矛盾——是两层：

- **轨迹层（不可变）**：派发/验证/归因的历史——逼近真实的路径，改了即失信；
- **理解层（可修订）**：计划、决策、文档结论——当前最佳理解，必须可被新证据推翻。

与 git 同构：commits 不可变，HEAD 可移动。**节点间共享的不是结论快照，是逼近轨迹+当前指针；多人协作的本质是互相引用轨迹、校准指针。**

## 三、两个硬骨头（按难度排序）

1. **决策多主体化（最硬）**：单点签准变多人共识，但不能等权投票——节点权重应来自**过程信誉（垒的厚度）**：「带阻尼共识」的阻尼=过程证据质量。哲学题（谁的判断算数）与工程题（并发写的一致性边界）同源。
2. **上下文共享（其次）**：共享单位不是全量上下文（重且踩主权边界），是**可引用的最小过程单元**（一份收据、一段归因推理链）——「不给对方看整个脑子，给对方看『我为什么这么判断』的证据包」。

主权公理的网络落点：**共享的是证据与判断，不是认知基底。**

## 四、Valve：人才密度换管理层的上限实验

去浪漫化的三面：公开叙事（无层级/桌子带轮子/同行评议）；阴暗面（隐藏权力层、评议人缘化、脏活无人做、核心成员出走）；隐性支柱（隐形 owner 权、利润冗余养自组织、行业天才密度分布）。

三条启发：

1. **Valve 没有消除熵减成本，是换形态**：管理层成本→招聘筛选（前置）+机会成本（脏活空缺）+政治摩擦。无免费秩序，但 exchange rate 更优——人才密度换掉了管理层。
2. **主观评议必然政治化**（同行评薪→人缘竞赛；Greenlight 人工评审→垃圾泛滥→被算法取代）：**过程证据是客观评议的原料；垒的厚度是 agent 时代的人才密度。**
3. **最扁的组织也有隐形 owner**：方向性熵减源头压不掉只能显性化——组织进化的方向是无中心幻觉→**中心契约化**。

合拢：**Valve 用人才密度换管理层；认知共创网络用过程证据密度换平台权威。**

产品侧对应：任务分配从中央指派到池化自取（顺序是先垒证据后开市场）；消费端形态对标创意工坊但补上其主权缺口（资产锁定）——「创意工坊+资产可携带」是组织网络与生态网络都未给出的第三种形态。

## 五、广场协议六特点（提案）

广场=认知共创网络的公共层。问题：多个认知主体如何不交出认知主权而协作逼近真实？

1. **分层可见性（gevulot 原则）**：每份认知资产的可见性可编程、随语境协商——私域（认知基底：记忆、经验、未外化判断）与公域（过程证据、已发布判断）物理分离，**边界由协议执行，不由平台政策执行**。
2. **轨迹不可变+指针可修订**：流通单元是可验证轨迹，共识指针独立一层可移动。
3. **共识权重=过程信誉**：判断的分量由可验证过程履历决定，不由身份/人缘/算力决定——Valve 教训与 Greenlight 教训的协议反面。
4. **回流契约**：共创负熵的归属分配内置于协议——分成是协议属性不是平台恩赐。
5. **互验性**：任何节点可验证任何「共识」背后的过程证据——不可验的主张无共识权重。
6. **退出权（反 Sobornost 保险）**：节点可携带全部资产（记忆、轨迹副本、信誉记录）离开——**广场必须可放弃，才不会变成监狱。** 强制数据可携带是协议的硬条款。

（六特点五日后裁定：原则层全部采纳；特点 3 与 6 的工程含义缓至协议工程化时细化。）

## 六、《量子窃贼》对照：两种公私结构

gevulot（忘川城隐私协议）：「公与私不是两个空间，是每个人可编程的频段」——默认共享的社会里个体用协议划界，边界公开可协商。本文将其从世界观层落到协议设计层：**gevulot=广场特点 1 的文学原型**。

对极是 Sobornost（强制拷贝意志的集体）：个体认知被复制、同质化、终归于中心意志——**平台捕获的终极形态，认知的炼油厂**。两文明即两岔路：自愿分层共享 vs 强制全共享；主权公理在科幻尺度上的正反例。

## 七、靠近路径（五步，不跳步）

1. **收据设计时考虑外部验证者**（非仅内部审计）——最近的 concrete 动作点；
2. **收据跨仓引用**：A 域收据可被 B 域验证——只动证据互认，不动决策权；
3. **裁决域扩展**：部分域裁决权可委托他节点——双人试点的前置；
4. **消费端试验田**：创意工坊形态+gevulot 式分层+资产可携带——轻量多人广场雏形；**游戏=广场协议天然试验场**（低风险、高频、可观测）；
5. **不可伪造层为第一块砖**：广场地基与门面同一件事。

## 八、共识形态：局部共识+引用聚合（非全局账本）

广场不需要区块链式全局账本：每节点维护自己的理解，通过引用他人轨迹更新，**分歧显式记录**（认知冲突一等公民——理解级分叉+解决时间线，非文本级合并冲突）。更像 git 分支模型而非以太坊；全局真相不必要，必要的是**可追溯的分歧与合流**（学术引用-反驳结构的过程化）。
