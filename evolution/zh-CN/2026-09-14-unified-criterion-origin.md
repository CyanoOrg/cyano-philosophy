# 过程性 = 路径依赖的负熵积累：四尺度统一判据（宏大串联）

> **演化档案 · 第二部 · 第 4 篇（部首）**。09-14 定稿。前一日（第一部三篇）的汇合假设在此形式化。原文脱敏收录，编者按见文末。

---

**问题**：四条线（桑德森/曾鸣/LeCun/Sutton）为什么是同一件事；把汇合假设形式化之后，能推出哪些可操作结论。

## 一、统一判据

**过程性 = 被过程改变的能力 = 状态中积累了路径依赖、不可廉价复制的秩序（负熵）。**

「被过程改变」要拆成三个必要条件，否则流于口号：

1. **积累**：状态发生改变且留存——不是每次归零重来。
2. **路径依赖**：状态由具体经过（哪些事故、哪些修复、哪些判断）塑形；换一条路到不了同一状态，快照搬运无效。
3. **不可廉价复制**：复制产出物 ≠ 复制能力。拷走产物的人得到了容器，没有得到垒。

三个条件独立可测：一个系统可以有积累而无路径依赖（均匀磨损）、有信息量而无不可复制性（可拷贝的数据）、有产物而无过程（生成模型）。

## 二、四尺度表

| 尺度 | 判据实例 | 危机诊断（同一句话的现形） |
|---|---|---|
| **个体**（桑德森） | 被创作过程改变的创作者——「书是收据，你才是艺术品」；Data 判据：为成长而创作、因创作而改变 | AI 跳过「成为创作者」的旅途 |
| **组织**（曾鸣） | 被自身运行改变的组织——战略从人机协作网络中涌现，「组织是战略的生成系统」 | 无生成能力的科层 |
| **机器**（LeCun/Sutton） | 被交互经验更新的内部状态——LeCun 押世界模型（抽象空间预测），Sutton 押经验学习（信号源切换：增量不在人类语料，在交互经验） | 无世界模型、无经验的语言统计 |
| **市场**（真实感变迁） | 给路径依赖积累定价——价值锚从产物外观迁移到过程证据 | 合成产物淹没信号 |

四个危机诊断是同一句话：**产物引擎没有过程**。反向统一更锋利：无轨迹的 LLM session 是绝热的（每次醒来最大熵开局，无跨 session 交换）；无记忆的组织是绝热的；外包了练习的人是绝热的；只看产物的市场是绝热的。**绝热 = 无积累 = 判据取零**——四条线诊断的病是同一个。

一行总结：**文化是人群的耗散结构，轨迹/记忆/进化是 agent 的耗散结构，真实感定价是市场对耗散结构的标价。**

## 三、为什么是「负熵积累」而不是「信息量」

- 信息可以拷贝（容器），积累的秩序不可——差别在路径依赖与载体耦合，不在比特数。
- **Sutton**（《The Bitter Lesson》《Era of Experience》）给出学习侧答案：智能的下一个增量不在人类语料（已压缩殆尽），在与环境交互的经验里——学习信号源的切换是过程性在训练侧的对应物。
- **Hinton**（mortal computation）给出载体侧答案：知识与硬件共存亡，「死」正是不可拷出的来源。agent 版翻译：坚持让工作状态积累对*这个*代码库、*这些*事故的特异性，等于**有意选择不可移植性 = 选定身份**。
- **LeCun**（JEPA）给出预测侧答案：世界模型的操作定义 = 在抽象表示空间预测自身动力学、丢掉不可预测的细节。能力来自访问结构而非规模。

三条答案合拢：**知识长在载体上（Hinton）、以经验而非语料为源（Sutton）、以预测而非重建为形（LeCun）**。

## 四、Agent 世界模型的操作化（本文核心增量）

前日猜测「Agent 的世界模型可能是工作过程的状态空间」在此具体一步：

**不预测 token 级轨迹（那是像素级，没戏）；预测相变：**

- **盆地归属**：这个任务会进重试盆地/失败盆地吗？
- **垒接近度**：当前漂移离红线多远？
- **侵蚀速率**：某条规范的流量是否滑向阈值？

即：**agent 世界模型 = 工作过程状态空间里的相变预测器**。与 JEPA「在抽象空间预测」同构——轨迹嵌入是表示空间，盆地与垒是其中的可预测结构，token 序列是被丢掉的细节。

**与觉知的合流点**：侵蚀率监测器在这个框架下不是运维工具，是**世界模型的第一块砖**。觉知的升格路线：记录秩序（结果指标）→ 测侵蚀速率（过程指标）→ 预测相变（过程动力学）。

**可证伪预测**（使其不只是叙事）：若假设成立，用轨迹状态嵌入训练的动力学模型，在「任务将进入重试盆地」上应给出高于基线的提前量。可设计为评估实验——**世界模型假设因此是可检验的工程命题，不是信仰**。

## 五、战略句与五层落位

给 agent 建造的整套东西（派发→验证→轨迹→归因→记忆→进化）= **把 agent 从绝热会话变成耗散结构的全套机制**。真实感变迁意味着市场正在学会给耗散结构标价。定位一句话：**做并展示 agent 的耗散结构本身**。

对五层图景的落位：引擎层是代谢通道，编排层是自组织动力学，角色层是分化出的细胞态，觉知层是这套结构的自我感知（兼世界模型雏形），皮肤层是它对外可见的形状。

**其上是第零层**：四公理——过程即价值、经验即智能、主权即尊严、真实即时间。本文的统一判据是过程公理的机制化。
