# 判据库（criteria/）

> 从实践讨论蒸馏的裁决工具，六件：c1 统一判据 / c2 生产分配门槛 / c3 验真质询 / c4 可验证性天花板 / c5 连续调谐 / c6 分配单位。每件结构：定义 → 判定 → 溯源 → 与种子的关系。

## 判据使用决策流

```mermaid
flowchart TD
    X["断言 / 方向"] --> V{"C3 验真质询<br/>证据何在？谁能复验？"}
    V -->|"任一问含糊"| DROP["降级为待验证信息<br/>不得驱动行动"]
    V -->|"两条质询皆明<br/>（等级 L0-L3 随链取最低）"| D{"C2 生产分配门槛"}
    D -->|"生产端 ∧ 分配端皆过"| GO["可立项"]
    D -->|"只过生产端"| HOLD["能做，但不该做"]
    GO --> U{"C1 统一判据<br/>积累？路径依赖？<br/>不可廉价复制？"}
    U -->|"三条件齐"| T["过程性成立<br/>积累为可验证轨迹 C6"]
    U -->|"缺一"| F["『有产物无过程』"]
    C4["C4 可验证性天花板<br/>（体系边界：边界外不承诺不计价）"] -.约束.- D
    C5["C5 连续调谐<br/>（协作形态：中间状态不失真）"] -.约束.- T
```
